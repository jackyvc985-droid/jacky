# Mis Tareas

App web instalable (PWA) que funciona en computadora y celular, incluso sin internet.

## Usar
Abre `index.html` con un servidor local, por ejemplo: `python3 -m http.server 8000` y entra a http://localhost:8000.

Para instalarla: en el navegador, "Instalar app" (PC) o "Agregar a pantalla de inicio" (celular).
Los datos se guardan en el propio dispositivo (localStorage).
