# Papeles de trabajo administrativos (México)

17 plantillas en Excel listas para vender, con fórmulas automáticas, listas desplegables,
formato de impresión y hoja de instrucciones en cada archivo.

| Carpeta | Plantillas |
|---|---|
| `1_Contabilidad_y_Finanzas` | Ingresos y gastos, caja chica, flujo de efectivo anual, cuentas por cobrar, conciliación bancaria |
| `2_Recursos_Humanos` | Asistencia, nómina simplificada, vacaciones (LFT), evaluación de desempeño, solicitud de vacaciones/permiso |
| `3_Inventarios_y_Compras` | Control de inventario, kardex costo promedio, orden de compra, cuadro comparativo de cotizaciones |
| `4_Documentos_y_Actas` | Cotización, recibo de pago, minuta de reunión |

Regenerar: `python3 generar_plantillas.py` (requiere `openpyxl`).
Convención: celdas amarillas = captura, grises = cálculo automático.
